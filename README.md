## INSTALLATION

1. Install Python 3.5.2 (python-3.5.2-amd64.exe)
	- https://www.python.org/downloads/release/python-352/

2. Install Visual C++ Redistributable for Visual Studio 2015 (vc_redist.x64.exe)
	- https://www.microsoft.com/en-ca/download/details.aspx?id=48145

3. Install dependencies from the command line using pip (located in the .../Python35/Scripts folder)
	- pip install sip==4.18.1
	- pip install PyQt5==5.7
	- pip install QScintilla==2.9.3
	- pip install appdirs==1.4.0
	- pip install jedi==0.9.0
	- pip install six==1.10.0
	- pip install python-dateutil==2.5.3
	- pip install pypyodbc==1.3.6
	- pip install numpy==1.11.1
	- pip install cycler==0.9.0
	- pip install pyparsing==2.0.7
	- pip install pytz==2015.7
	- pip install matplotlib==1.5.2
	- pip install xlrd==1.0.0
	- pip install xlwt==1.1.2
	- pip install xlutils==2.0.0

4. Clone or download the ORIGAME project to your system

5. Run "python origame_gui.py" in the project root folder
	- Be sure to launch ORIGAME using the version of Python installed above (.../Python35/python.exe) in case multiple versions of Python exist on your system.
